# TopMart ERP – Factory Material Flow Dashboard

Create a modern responsive web dashboard (React + Tailwind CSS + Supabase/Firebase or SQLite backend).

Theme:

* Professional factory ERP
* Dark mode
* Green (#16a34a) primary
* Blue for incoming materials
* Orange for production
* Purple for finished goods
* Smooth animations
* Live updating dashboard

---

## Goal

Build a real-time Material Flow Monitoring System.

The system must automatically calculate:

* Raw material balance
* Department (Work In Progress)
* Finished goods
* Container balances
* Employee responsibility
* Material movement history

Everything must update automatically.
